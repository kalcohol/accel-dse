        未单列的发布（仍可按 id 评估，也都参与参数核对）

          这是什么

          面向 LLM 推理加速器的解析式设计空间探索：模型按官方发布（HF config + safetensors 头，dtype 按发布）建模，生成逐 rank 的算子图，映射组织（OS / WS / GEMV / 可重构）、SRAM 端口、存储器与并行布局都是设计变量，然后做存储规划、流水调度与精确的布局 / batch 搜索。

          诚实声明

          范围

          • 只覆盖 LLM 推理（decode / prefill / goodput）。视频与蛋白质领域在 0.40 暂时下线：v2 校验流水线目前只覆盖 LLM，待对应模型按发布接入并通过校验后再开放。
          • 「架构代理」：模型含有尚未逐项建模的结构（如超连接、n-gram 查找表、压缩稀疏注意力），参数按发布计入，部分计算按近似处理。
          • dtype 按发布；芯片不支持的格式按反量化 / 上转换计入向量单元开销。自由覆盖只作为标注的 what-if。
          • 不做功耗 / 面积 / 成本估计。

          校验

          V1 参数量对照发布（55 个发布，±0.5%）；V2 H100 类配置的趋势区间；V3 对照 GenZ（LPDDR 与可比的 HBM 点）。详见 docs/MODEL.md，命令行 python3 -m accel_dse validate。
