        覆盖度指本工具对该模型结构的建模覆盖程度，与模型好坏无关：完整 全部算子按发布结构逐项建模；部分 主干逐项建模，个别机制近似（见「近似之处」）；架构代理 含未建模的结构，结果只作量级参考。VLM 的视觉编码器（ViT + 合并 / 投影）按发布配置与预处理器逐项建模（图像数默认 0 = 只算文本，在「服务」里设图像数与分辨率）；视频生成默认整条 pipeline：DiT 去噪主干 + 文本编码器 + VAE 解码（按发布检查点头建模，与去噪串行「假设」；组件放置可选常驻 / 文本编码器分片 / 顺序卸载，默认自动取第一个放得下的；工作负载里取消勾选即只看 DiT）。

          这是什么

          面向推理加速器的解析式设计空间探索（LLM / VLM；视频生成 DiT 与蛋白质语言模型的首批发布）：模型按官方发布（HF config + safetensors 头，dtype 按发布）建模，生成逐 rank 的算子图，映射组织（OS / WS / GEMV / 可重构）、SRAM 端口、存储器与并行布局都是设计变量，然后做存储规划、流水调度与精确的布局 / batch 搜索。

          诚实声明

          范围

          • LLM 推理：decode / prefill / goodput；VLM 另计视觉编码器（prefill 时运行，图像 token 进入 prompt / KV；0.62 起）。
          • 视频生成（0.41 起）：Wan2.1 / Wan2.2、CogVideoX、HunyuanVideo、LTX-Video、Mochi、Open-Sora、MiniMax-H3 的 DiT 去噪主干（按各自发布的注意力形式），每个去噪步按 CFG 前向 1–2 次；默认整条 pipeline：文本编码器 + 去噪 + VAE 解码（按发布检查点头建模，组件放置可选常驻 / 分片 / 卸载），工作负载里可只看 DiT；指标为单段延迟、每帧延迟、帧/s/卡。
          • 蛋白质（0.41 起）：ESM-2（650M / 3B）编码器一次前向；结构预测 ESMFold、OpenFold、AlphaFold2、Boltz-1、Protenix（主干 / 循环 / 扩散按发布配置）；指标为批延迟、序列/s/卡、残基/s/卡。其余结构模型仍为目录条目；分子动力学 / 力场不在范围内（目录中也无此类条目）。
          • 「架构代理」：模型含有尚未逐项建模的结构（如超连接、n-gram 查找表、压缩稀疏注意力），参数按发布计入，部分计算按近似处理。
          • dtype 按发布；芯片不支持的格式按反量化 / 上转换计入向量单元开销。自由覆盖只作为标注的 what-if。
          • 不内置任何能耗、面积数值，也不静默填电价：能耗 = 动作计数 × 用户填写的每动作能耗；面积只是用户给出密度时的代理预算检查；绝对电费（$/单位）仅在用户填写 $/kWh（或选电价预设）且有能耗表或 TDP 时由洞察计算。

          校验

          V1 参数量对照发布（55 个发布，±0.5%）；V2 H100 类配置的趋势区间；V3 对照 GenZ（LPDDR 与可比的 HBM 点）。详见 docs/MODEL.md，命令行 python3 -m accel_dse validate。
