          这是什么

          面向推理加速器的解析式设计空间探索（LLM / VLM；视频生成 DiT 与蛋白质语言模型的首批发布）：模型按官方发布（HF config + safetensors 头，dtype 按发布）建模，生成逐 rank 的算子图，映射组织（OS / WS / GEMV / 可重构）、SRAM 端口、存储器与并行布局都是设计变量，然后做存储规划、流水调度与精确的布局 / batch 搜索。

          诚实声明

          范围

          • LLM 推理：decode / prefill / goodput；VLM 只算语言主干。
          • 视频生成（0.41 起）：Wan2.1-T2V（1.3B / 14B）与 CogVideoX（2b / 5b）的 DiT 去噪主干，全 3D 注意力（不是时空分解），每个去噪步按 CFG 前向 1–2 次；指标为单段延迟、每帧延迟、帧/s/卡。文本编码器与 VAE 未建模（覆盖「部分」）。其余视频模型（HunyuanVideo、Wan2.2、LTX、Mochi 等）仍为目录条目。
          • 蛋白质（0.41 起）：ESM-2（650M / 3B）编码器一次前向；指标为批延迟、序列/s/卡、残基/s/卡。AlphaFold / ESMFold / Protenix 等结构预测模型仍为目录条目（未接入）。分子动力学 / 力场不在范围内（目录中也无此类条目）。
          • 「架构代理」：模型含有尚未逐项建模的结构（如超连接、n-gram 查找表、压缩稀疏注意力），参数按发布计入，部分计算按近似处理。
          • dtype 按发布；芯片不支持的格式按反量化 / 上转换计入向量单元开销。自由覆盖只作为标注的 what-if。
          • 不做功耗 / 面积 / 成本估计。

          校验

          V1 参数量对照发布（55 个发布，±0.5%）；V2 H100 类配置的趋势区间；V3 对照 GenZ（LPDDR 与可比的 HBM 点）。详见 docs/MODEL.md，命令行 python3 -m accel_dse validate。
